# Mi Gym

App web para el gimnasio: rutinas con calentamiento, modo entreno con temporizador de descanso, biblioteca de 188 ejercicios ilustrados, registro de comidas con objetivo en déficit, menús fit, lista de la compra, medidas de báscula inteligente, calendario por fecha y exportación a Excel.

Todos los datos se guardan **solo en el móvil de cada persona** (no hace falta cuenta).

## Instalar en el iPhone
1. Abre https://miluskatalaverano-dev.github.io/mygym/ en **Safari**.
2. Toca **Compartir** → **Añadir a pantalla de inicio**.

## Copias de seguridad
En **Registro → Exportar mis datos** descarga la copia de seguridad (.json) de vez en cuando. Con «Restaurar una copia» la recuperas en un móvil nuevo.
